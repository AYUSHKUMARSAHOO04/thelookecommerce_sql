# Result Index

Maps all 90 business questions developed in this project to whether their output was exported into the decision-analysis layer, and why.

**Output Selection Methodology:** Although 90 SQL business questions were developed and analyzed, the decision-analysis layer focuses on outputs that are concise, decision-relevant, and useful for executive interpretation. Several queries (notably per-product and per-brand breakdowns) return thousands of rows — these were retained and fully runnable at the SQL layer (`sql/`) but excluded from the executive analysis to avoid noise. This is a deliberate curation decision, not missing work — every one of the 90 questions has a working, documented query in `sql/`.
